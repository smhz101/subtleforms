# Changes in 2.11.0

## Added

- The form block settings have an "Edit this form" link under the form picker that opens the builder in a new tab, and the picker has more space above the toggles.
- The Password field can require an uppercase letter, a lowercase letter, a number or a symbol, and a minimum strength. The strength meter is now a coloured four-step bar, with a checklist of the rules.
- The Phone field has ready-made input masks: US and Canada, 999-999-9999, UK, Australia, India and international. "Phone" is now called "Automatic (by country)" on Phone fields.

## Changed

- With Require confirmation on, "The passwords do not match." now shows under the confirm password input while the visitor types, and goes away as soon as the two match.

## Fixed

- Checkbox, radio and multiple choice options in the builder canvas are tighter and match the frontend: 16px controls, 14px text and a 6px gap between rows.
- A password field with "Require confirmation" now sends the confirmation with the form, so matching passwords go through and a mismatch or an empty confirmation is blocked.
- The time, date and time, and colour fields now look finished: labelled hour and minute columns with Now and Done buttons, and a colour field that matches the other inputs.
- A form block written as a self-closing comment, for example by hand, with WP-CLI or from a pattern, no longer shows "Block contains unexpected or invalid content" in the editor.
