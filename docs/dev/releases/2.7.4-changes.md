# Changes in 2.7.4

## Added

- The SubtleForms menu and its Submissions item show the number of unread entries in a bubble, like the Comments menu, with counts above 9 shown as 9+.

## Changed

- SubtleForms has a new logo: the admin menu icon, the header mark and the block icon now use it.
- Notices from WordPress and other plugins now appear under the SubtleForms header instead of above it.
- SubtleForms screens have a footer with the version, documentation and support links and the list pagination, while the page content scrolls between the header and the footer.
