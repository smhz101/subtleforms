# Changes in 2.7.0

## Added

- Web addresses and links written as [text](https://example.com) in a form's confirmation message are now clickable; only http, https and site-relative links are allowed and anything else stays plain text.
- Add-ons can register their own panel in the form builder under Integrations, so Pro can offer Salesforce, Pipedrive and Close there.
- Extension points for add-ons: field type overrides, logic evaluators, Reports panel slots, form mount hooks and a form-deleted action, with Pro placeholders in the builder and Reports.

## Changed

- Advanced conditional logic (any-match, groups, more operators, step, action and confirmation rules) is now part of SubtleForms Pro; basic show and hide rules stay free and saved advanced rules are ignored without Pro.
- Form analytics (views, conversion, the form funnel and the Reports panels) is now part of SubtleForms Pro; entry counts, dashboard totals and the spam card stay free and stored counts are kept.
- Uploading several files in one field is now part of SubtleForms Pro; a saved multi-file field accepts one file without it.
- Picture Choice is now part of SubtleForms Pro; forms that use it keep working as a plain choice field until Pro is active.
- The Pro upgrade notes now say SubtleForms Pro has 52 templates, including scored quizzes and five calculators.
- Removed two settings that were saved but never used: the WooCommerce product and currency fields.
