# Changes in 2.8.1

## Added

- HubSpot is built in: connect a HubSpot service key (a legacy private app access token also works) under Settings, Integrations, CRM, then switch HubSpot on for a form to create or update a contact for each entry, with field mapping, custom properties, a consent checkbox and a line in each entry's activity log with an Open in HubSpot link.
- The SubtleForms menu shows the total number of entries as a short count (1k, 1.2k, 12k) with the full number as its tooltip.

## Changed

- The admin bar icon lines up with the other items, the bubble keeps its place on hover, and the SubtleForms menu has an Upgrade to Pro item on free sites.
- Every connection screen (Mailchimp, Brevo, Kit, MailPoet, HubSpot and webhooks) now has numbered steps in plain words, and each step on another website links straight to that page; a rejected HubSpot key says to paste the new one.
- All notices in the admin follow WordPress styling: square corners, the core border colours and a white background.
- The "How to connect" steps on every service screen sit in an accordion that starts open until the service is connected, then closed, and remembers your choice.

## Fixed

- Forms with AJAX off lost every entry: the classic post handler was only registered on REST requests (broken since 2.4.0). The block default is now AJAX on, so form blocks saved without an AJAX setting now submit with AJAX.
- The New form page has the same space above its heading as the other screens.
- A form post without AJAX from a logged-in visitor now carries the REST nonce; a post without a valid one is handled as a guest post, so a cross-site post cannot act as the logged-in user.
- Behind Cloudflare each visitor now has their own rate limit: the visitor address from Cloudflare is used for requests that come from Cloudflare's published ranges without turning on a setting, and Security & privacy shows a dismissible notice when it sees Cloudflare in front of the site.
- The CSV export includes every matching entry instead of stopping at the newest 10,000, and the answer now carries the number of entries exported.
- The CSV export, Export selected included, is now sent as a file while it is written instead of being built in memory, so a very large form no longer runs out of memory, and a download that cannot start says why instead of failing silently.
- Notification emails are no longer lost when WP-Cron runs late: the queued email waits in the options table until it is sent instead of a transient that expired after 6 hours, and an email whose stored copy is gone is built again from the saved entry.
- A logged-in visitor whose page was open for a long time can send a form with the time trap again (the form retries once with a fresh token instead of repeating "Please send it again"), and a form with AJAX off no longer creates a second entry when Submit is clicked twice while the page is posting.
- An answer with a "<" in it, such as "Budget <5000", is saved and emailed in full instead of being cut at that point, and an entry is no longer lost when the visitor's browser sends a User-Agent longer than 255 characters (Facebook and Instagram in-app browsers on iPhone).

## Security

- The Rich Text field now cleans its starting value with the same allowlist as typed text, so a value filled in from the block, a default or the page address can only show the allowed formatting and safe links.
