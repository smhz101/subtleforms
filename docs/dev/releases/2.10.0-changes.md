# Changes in 2.10.0

## Added

- Text fields such as Name and Company now tell browsers what they ask for, so autofill and password managers can fill them, and each field has an Autofill setting to choose or turn it off.
- Dropdowns jump to the option you type, and lists with more than 15 options have a search box.
- Site admins now see a short note where a form embed points to a missing or unpublished form, and visitors with JavaScript turned off see a message instead of an empty space.
- Multi-step and conversational forms keep a visitor's answers and step if the page is reloaded, until the form is sent.
- Bulk actions on Submissions can apply to every entry that matches the current view, not only the visible page.

## Changed

- The builder warns when a Repeat container has no fields, since it shows nothing on the form.
- New sites now keep their forms and entries if SubtleForms is deleted (Settings, Advanced), and the Plugins screen says whether deleting will remove them. Existing sites keep their current choice.
- Spam entries no longer appear in All, Read and Unread or count toward the unread badge. They stay in the Spam tab, where Not spam moves them back.
- The builder warns about fields that are not shown on the form yet, such as Post Selection, and the Password field says the password is not saved.

## Fixed

- A condition sent on a notification through the API is no longer dropped, and the entry log now says when a notification was sent without its conditions being checked because SubtleForms Pro is not active.
- The Form filter on the Submissions screen now lists every form, not only the newest 20, and can be searched.
- The SubtleForms block's form picker lists every published form, with search, and shows each form's id.
- In the form builder, Cmd/Ctrl+Shift+Z and Ctrl+Y now redo the last undone change.
- The Build, Settings, Entries and Preview tabs in the form builder keep their names for screen readers and show a tooltip when the window is too narrow for their text.
- Conversational forms keep the Next button on screen on shorter windows, and after Enter the cursor is ready in the next question.
- The entry panel shows the country name for a Country answer instead of its code.
- Conditional logic rules that compare a date or time with greater than or less than now work; they used to never match.
- The email step in the submission log now shows From, Reply-To, format and a readable text preview instead of cut-off HTML.
- HTML notification emails now include a plain text version, which helps them stay out of spam folders.
- The sender domain warning no longer fires on www sites, {admin_email} follows the admin email set in plugin settings, and the email notification editor shows who mail is sent from.
- Exporting the entries of all forms now uses each field's label as the column heading instead of its internal key.
- Export CSV now works on the Starred, Unread and Read tabs, and says so when there is nothing to export.
- Forms set to inherit the theme style get comfortable padding and height on text boxes when the theme does not set any.
- The Star button in the entry panel now shows when the entry is starred, and stays in step with the star in the list.
- Phone answers are saved as the visitor typed them, with spaces kept, and a number typed with dots, such as 415.555.0100, is saved with spaces and passes validation.
- Rich text toolbar buttons are named for screen readers by their labels alone, Checkboxes created through the API render as checkboxes, and the builder flags a Chained Select that has no options yet.
- Entry dates in the list, the entry panel and its activity log now follow the time zone in Settings, General, so everyone sees the same time.
- Export selected from the Spam tab now exports those entries, and importing a package twice no longer duplicates its spam entries.
- Saving a form from a tab that was opened before someone else's save no longer overwrites their changes; the builder asks whether to reload or replace.
- An auto-reply that is not sent because submitter emails are off is now logged as Skipped with the reason, and the notification editor warns about it; new sites start with submitter emails on.
- A visitor who sends a form within the first seconds, for example after browser autofill, is no longer silently dropped by the spam time trap; the form waits a moment and sends.
- A CAPTCHA field without keys no longer blocks every visitor; it is skipped until keys are added, and only site admins see the setup message.
- Searching entries now finds answers written in Arabic, Urdu, Chinese, Cyrillic and other non-Latin scripts, including entries saved before this update.
- A form placed twice on one page now gives each copy its own field ids, so labels and error links point at the right copy.
- Opening an unread entry now lowers the Unread count straight away, and the entry leaves the Unread list when you close it.

## Security

- SubtleForms checks whether uploaded files can be opened from the web, for example on nginx, and shows the server rule to block them in Site Health and on SubtleForms screens.
