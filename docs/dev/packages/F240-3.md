# Package F240-3: Field options and builder behaviour

Repository: `subtleforms`. Release: Free 2.4.0. Branch from `release/2.4.0` as `pkg/F240-3`. Owner: Claude.

Standing rules: docs/dev/RULES.md. Bugs below are the whole task; each one needs a regression test.

## Instructions
Work through each ID; the QA row says what is wrong. Pickers get full keyboard support (typeahead, arrow grid, focus return, aria-invalid and aria-required), the other items are local fixes.
