# Package F239-4: Free templates clean-up

Repository: `subtleforms`. Release: Free 2.3.9. Branch from `release/2.3.9` as `pkg/F239-4`. Owner: Cursor.

Standing rules: .cursor/rules/subtleforms.mdc. Bugs below are the whole task; each one needs a regression test.

## Instructions
For every template in src/Templates/FormTemplates.php: remove every webhook action that points at an example.com host; every template gets one enabled email action to {admin_email} with subject "New entry: {form_title}" and an empty message (sends {all_fields}). The Payment Form template uses Product, Order Summary and a short note that card payment needs SubtleForms Pro; it must have no text fields for card number, expiry or CVV. The Donation Form uses a Custom Amount. Add a WP test that loops every template: no example.com URL anywhere in its schema, no field key or label matching card|cvv|expiry, and at least one email action.
