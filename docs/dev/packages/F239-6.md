# Package F239-6: UI and UX before submission

Repository: `subtleforms`. Release: Free 2.3.9. Branch from `release/2.3.9` as `pkg/F239-6`. Owner: Cursor (Claude reviews).

Standing rules: .cursor/rules/subtleforms.mdc. Bugs below are the whole task; each one needs a regression test.

## Instructions
Follow the design system note in docs/dev/qa/2.3.8/ui-ux.md section 7 for every change (spacing, colour tokens, sentence case). Screenshots of before and after at 1440, 1024 and 390 for each fixed screen go in the PR description.
- Builder header never overlaps at 1280 to 1600 (UX2-01). Preview stage scales to the space left (UX2-02). Conversational choice questions render as a vertical option list (UX2-03). Coupon input flexible, Apply wraps under 400 px (UX2-04).
- Distinct error state with Retry on All Forms, Submissions and builder load; never fall back to the empty state on error (UX2-05). Builder save error says "Your changes are kept in this tab." with Retry and clears on success (UX2-06). Builder skeleton instead of the black screen (UX2-07).
- Presets: Dark surface paints its own background, Dark and Bold buttons reach 4.5:1, dark radios and checkboxes readable (UX2-08).
- Dashboard and Reports count the same 7 days the same way (UX2-09). Field delete shows "Field deleted. Undo" (UX2-11). One vocabulary: Standard, Multi-step, Conversational everywhere (UX2-12, UX2-14).
- Accessibility: focus ring not clipped, labelled Rows per page select, chart bars as role="img" with a text summary, muted text at least #707070, 24 px targets (UX2-20 to UX2-24).
- Quick Start Wizard creates the form (FF-06). Builder status badge correct after autosave (FF-07).
Also from the UI plan: drop the "Push your changes live?" confirmation on Update (keep it for first Publish).

## Bugs (19)

### UX2-01 (P1) new in 2.3.8
- Screen: Builder header
- Repro: 1440x900, open any form, change a label (status becomes "Unsaved changes") or trigger a save error
