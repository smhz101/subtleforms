# Package F239-2: WordPress.org hygiene: AI tab, readme, zip, uninstall, guards, translations, logs

Repository: `subtleforms`. Release: Free 2.3.9. Branch from `release/2.3.9` as `pkg/F239-2`. Owner: Claude.

Standing rules: docs/dev/RULES.md. Bugs below are the whole task; each one needs a regression test.

## Instructions
- Remove the AI assistant tab completely: component, Settings group entry, ai_* keys in Schemas and Settings defaults, and delete stored ai_* options in the upgrade routine.
- readme.txt: start from docs/dev/wporg-readme.txt (already validated). Contributors: smhz101. Requires at least 6.6 in readme, plugin header and the Activator version check. Keep the changelog to the last 3 versions; move the full history to a new changelog.txt in the plugin root (add it to the gulp include list). After package F239-1 merges, check the "Pro" paragraph matches the split.
- Zip (gulpfile.js and .distignore): exclude src/Validation/EXAMPLES.php (or delete it if unused), assets/README.md, the placeholder SVGs (banner, icon, screenshot) and every *.map file; add docs/, .cursor/ and _plan/ to .distignore; remove composer.json from .distignore; make `gulp dist` run `composer install --no-dev --optimize-autoloader` in the staging copy (or document the step in RELEASE.md).
- uninstall.php: drop every SubtleForms table (including api_logs, coupons, coupon_uses), every subtleforms_* option and site option, every transient by LIKE, every user meta the plugin writes (inbox density and others), and clear every scheduled hook with wp_clear_scheduled_hook. Loop all sites on multisite (FF-31). Respect a "Keep data on uninstall" setting if present.
- Guards: `if ( ! defined( 'ABSPATH' ) ) { exit; }` at the top of every PHP file; the main file uses exit, not wp_die.
- Admin inline <style> blocks move to wp_add_inline_style on a registered handle (WP2-19). Replace the do_action('wp_enqueue_scripts') theme-style capture in AdminMenu with wp_get_global_stylesheet() plus the active theme stylesheet URLs (WP2-20, FF2-20).
- wp_set_script_translations for the admin, frontend and block script handles, and a `npm run i18n` script that makes the POT and JSON files (FF-23, WP2-21).
- Logging (WP2-22, FF2-22): every log call goes through Logger with the right level; nothing at ERROR level for normal events; no print_r/var_export unless debug is on; no unconditional error_log on bad nonces.
- FLD2-01: make sure `npm run build:all` runs in the release script so the zip never ships a stale bundle; add a check that fails the dist task if build/ is older than resources/.
