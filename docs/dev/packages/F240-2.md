# Package F240-2: Labels and formatting in output

Repository: `subtleforms`. Release: Free 2.4.0. Branch from `release/2.4.0` as `pkg/F240-2`. Owner: Claude.

Standing rules: .cursor/rules/subtleforms.mdc. Bugs below are the whole task; each one needs a regression test.

## Instructions
One formatter used by the entry screen, emails, CSV, PDF data and integrations: choice labels not values, Yes/No for booleans, matrix with row and column names, dates and times in the field display format, uploads as names with admin links, long labels shortened in headers, admin label used. Entries reference the schema version instead of a full copy (FF-30) with a migration that keeps old entries readable.

## Bugs (11)

### FA-10 (P2) Still open
- Repro: Matrix single (rows Speed, Price) and multi (Mon x AM/PM); submit and read email, CSV, PDF
- Expected: "Speed: Good; Price: OK", "Mon: AM, PM"
- Actual: "Good, OK" and "Mon: Yes, Yes"; entry detail multi shows "AM: true"
- Likely cause: Answer formatting for checkbox_grid in FieldMapper / EmailAction drops the keys
- Report: docs/dev/qa/2.3.3/fields-advanced.md
