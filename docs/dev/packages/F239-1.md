# Package F239-1: Free and Pro split, trialware removal, upsell copy, prefixes

Repository: `subtleforms`. Release: Free 2.3.9. Branch from `release/2.3.9` as `pkg/F239-1`. Owner: Claude.

Standing rules: docs/dev/RULES.md. Bugs below are the whole task; each one needs a regression test.

## Instructions
Goal: no feature code in free is switched off by a license. Follow the split in the plan:
- Unlock in free (remove the capability gate, the Pro badge, the lock UI and the upsell modal for these): CSV export, Reports (views, submissions, conversion) with a new Settings switch to turn view counting off, full conditional logic (any/all, OR groups, every operator, conditional emails, webhooks and confirmations), Picture Choice, multi-file uploads, payment fields (Product, Priced Options, Custom Amount, Fixed Fee, Order Summary, Coupon Code), coupons, Webhooks and Analytics settings panels.
- Remove from free entirely (code moves to Pro 2.4.0 in package P240-1): Signature and Calculation field types, their renderers, lazy chunks, validators, builder library entries and formula engine usage. Keep read-only display of stored signature images and calculation values in entries, emails, CSV and PDF data, so old entries stay readable. Add the hooks Pro needs to register field types with renderer, validator and pricing (document them in docs/hooks.md).
- Card Payment field stays a Pro field type (registered by Pro).
- Rewrite upsell copy: no "trapped", no "light up", no locked sample KPIs. A factual line plus a link, on SubtleForms pages only. Templates screen shows the free templates and one card "47 more templates in SubtleForms Pro".
- Rename global functions sf_is_pro_active, sf_is_feature_enabled, sf_show_upgrade_notice to subtleforms_*, keep the old names as deprecated wrappers only if Pro 2.3.3 calls them (grep the Pro repo), rename transients sf_upload_* and sf_rl_view_* to subtleforms_rl_*.
- Capabilities API (Capabilities::defaults, subtleforms/capabilities filter) stays as an extension point, but no default in free may be false for code that ships in free.
Test: with Pro absent, every unlocked feature works end to end; Signature and Calculation are absent from the library and a form saved with them renders without them; no Pro badge remains on a free feature.
