# Package F240-4: Free features and importers

Repository: `subtleforms`. Release: Free 2.4.0. Branch from `release/2.4.0` as `pkg/F240-4`. Owner: Cursor.

Standing rules: .cursor/rules/subtleforms.mdc. Bugs below are the whole task; each one needs a regression test.

## Instructions
Work through each ID. Importers: map Gravity and Fluent notifications, confirmations, containers, steps, logic and merge tags, and list what was skipped instead of dropping it silently.
