# Package F239-3: Security and data safety

Repository: `subtleforms`. Release: Free 2.3.9. Branch from `release/2.3.9` as `pkg/F239-3`. Owner: Claude.

Standing rules: .cursor/rules/subtleforms.mdc. Bugs below are the whole task; each one needs a regression test.

## Instructions
Imports sanitised exactly like a builder save (FF2-01). Guest submits work on cached pages (FF-03). Signed server-side time trap token, missing token is spam (FF-11, FF-12). Rejected submissions are never stored (FB-09, FA-24, FF-13, FLD2-17). Privacy exporter and eraser exact email matching and full coverage (FF-20, FF-21). Deleting a form deletes its entries, logs, files and schema versions (FA-19, FF2-21, FF-27). API log: no rows for unknown routes or anonymous noise, capped and rate limited (FF2-08). Settings save validation (FF-01, PRO2-01). Exports never silently empty (FF2-07). Rate limit policy matches the route (FF-28). Uploads use wp_handle_upload and WP_Filesystem, random protected folder, nginx note (WP2-18, FA-18).

### FF-03 (P1) Still open
- Repro: Serve a form page from a full-page cache older than the nonce lifetime (simulated by sending an expired X-WP-Nonce as a guest) and submit

- Actual: 403 `rest_cookie_invalid_nonce`. The visitor sees "Submission failed." and nothing is stored.

### FF2-01 (P1) new in 2.3.8
- Repro: Tools > Import forms with a SubtleForms file whose Custom HTML field content is `<img src=x onerror="...">` (or a label with markup); open the published page. Tools > Import submissions with a rich text answer `<img src=x onerror="...">`; open the entry. The Gravity/Fluent importer uses the same save path (GF html `content`, Fluent `html_codes`).
- Expected: Imported content is cleaned like a builder save (the normal save turns the same schema into `Name` and `window.__xs=1<img src="x">hi`)

- Likely cause: TransferService.php:128 and :182 call `saveSchemaVersion()` directly, skipping the FormsApi request validator and sanitiser (FormsApi.php:598). TransferService.php:307 stores the payload raw. SubmissionDetailPage.jsx:917 and frontend FieldRenderer.jsx:222/235 render HTML as stored.
- Report: docs/dev/qa/2.3.8/free-features.md
