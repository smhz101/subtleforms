type: Changed
The Date, Time and Date & time fields now use a typed input with an icon button instead of a button, so a theme styles them like any other field. The calendar has month and year views and skips days that cannot be picked, the time list steps by a minute step you choose, and the formats are presets with an example instead of free text. New options: first day of the week, earliest and latest date (a date or a relative date such as +7 days), no past dates, unavailable weekdays, earliest and latest time, and a default of today or now. The limits are checked on the server and in the browser with the same messages. Saved values do not change: dates stay Y-m-d, times H:i and date and times Y-m-dTH:i. A saved relative minimum such as today is now enforced on the server too.
