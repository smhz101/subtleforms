# SubtleForms Site theme

Block theme for subtleforms.com. Requires WordPress 6.6+ and PHP 8.1+. No build step.

- `theme.json` holds every design token (palette, type, spacing, radii, shadows, motion). Edit in Appearance > Editor > Styles.
- `styles/` holds the Ink (dark) style variation and the section styles (Ink, Moss, Paper) that appear in the Group block's Styles panel.
- `patterns/` holds every section as a block pattern. They show up in the inserter under "SubtleForms".
- `parts/` holds header, footer and announcement bar.
- `blocks/` holds two custom blocks: `subtleforms/path` (the Throughline) and `subtleforms/hero-media`.
- `assets/fonts/` holds the four self-hosted WOFF2 files and their SIL OFL licences.

See `docs/design-system.md` and `docs/editing-guide.md` in the repository root.
